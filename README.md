Proyecto de Titulación 

Aplicación Web para la Administración y Gestión de Trámites Parroquiales

Proyecto de titulación desarrollado como parte del proceso para obtener el título de Tecnóloga Superior en Desarrollo de Software.

La aplicación fue desarrollada para la Parroquia Santa María Madre de la Iglesia de Miraflores, con el propósito de digitalizar y facilitar diferentes procesos administrativos y trámites que anteriormente se realizaban de forma manual.

El proyecto fue desarrollado de manera individual en el año 2021, aplicando los conocimientos de programación y desarrollo web adquiridos durante la carrera.

Objetivo

Desarrollar una aplicación web que permitiera mejorar la administración y gestión de los trámites parroquiales, facilitando el registro, consulta y organización de la información.

Entre las funcionalidades desarrolladas se encuentran:

Gestión de usuarios.
Registro y consulta de información.
Gestión de trámites parroquiales.
Gestión de sacramentos.
Solicitudes de misas.
Gestión de visitas.
Agenda de actividades.
Emisión de certificados.
Registro de pagos.
Consulta de información.
Administración de documentos y registros.

Sobre el proyecto

La aplicación fue diseñada para organizar y digitalizar procesos que anteriormente se gestionaban mediante documentos y registros físicos.

El sistema cuenta con diferentes opciones dependiendo del tipo de usuario, permitiendo controlar el acceso a las funcionalidades administrativas y gestionar la información de acuerdo con los permisos correspondientes.

También se incorporó una opción relacionada con el registro de pagos. Para representar el método de pago utilizado en la parroquia se incluyó una referencia visual al sistema Deuna, utilizado ampliamente en Ecuador en ese período.

Arquitectura

La aplicación fue desarrollada utilizando el patrón Modelo-Vista-Controlador (MVC), separando la lógica de la aplicación, la presentación y el acceso a los datos.

La base de datos fue desarrollada en MySQL y la aplicación se ejecutaba inicialmente de forma local mediante XAMPP.
